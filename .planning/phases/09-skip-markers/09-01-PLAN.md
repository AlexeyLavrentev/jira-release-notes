<objective>
Establish the SKIP-01 data-flow backbone: the `<no-release-notes>` marker is detected by
validateReleaseNote, classified as a new 'skip' ValidationCategory, and excluded entirely from
the export document by buildDocumentDoc. This is the tracer slice — it wires one path (marker →
validation → type system → export exclusion) end-to-end and keeps tsc green by updating every
exhaustive Record over the category union in the same task.

Purpose: SKIP-01 (marker exclusion from the document) is the semantic core of Phase 9. Proving
this path first — with the TypeScript exhaustiveness forcing all consumers to handle 'skip'
atomically — de-risks the whole phase. SKIP-02 (selection visibility) is pure UI expansion that
builds on this proven category in Plan 02.

Output: Extended validation.ts (skip category), filtered group.ts (export exclusion), type-safe
IssueRow/MobileIssueCard Records, and a new validation.test.ts proving the marker contract.
</objective>
