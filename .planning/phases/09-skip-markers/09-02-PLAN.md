<objective>
Build the SKIP-02 visibility layer on top of the 'skip' category proven in Plan 01: skip tasks are
visible but visually demoted in selection (grayed, struck-through, Ban icon), filterable via a new
«Пропущенные» segment, counted in a new «Пропущено: N» counter, and rendered read-only in EditPage.
Also update the engineer writing guide to document the marker.

Purpose: SKIP-01 (exclusion) is useless without SKIP-02 (visibility) — the author must SEE which
tasks were dropped and why, so they can trust the exclusion and intervene (remove the marker) if a
task was marked skip in error. The display-only EditPage rendering (D-13/D-14) makes the
"intentional drop" semantic unambiguous in the editor too.

Output: Filterable, countable, visually-distinguished skip rows on desktop + mobile, a read-only
EditPage block for skip issues, and documented marker semantics for engineers.
</objective>
